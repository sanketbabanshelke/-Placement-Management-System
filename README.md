
# Placement Management System

## Project Description
A web-based Placement Management System developed using Spring Boot and MySQL.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Modules
1. Admin Module
2. Student Module
3. Company Module

## Features
- Student Registration and Login
- Student Profile Management
- Company Registration
- Student Information Management
- Job Application Management
- Placement Management
